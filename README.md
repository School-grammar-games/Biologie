# EduBioSim GitHub redirect repository

This repository keeps GitHub Pages redirects for old biology simulation links and the Netcup deployment workflow.

The live site is https://www.edubiosim.de/.

Netcup deployment files live in `_netcup_deploy/` and are uploaded by `.github/workflows/deploy.yml` when they change. Redirect files in the repository root are not deployed to Netcup.
